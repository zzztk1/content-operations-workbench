## 四、前后端产品化（曾不一致项 → 当前处理）

1. **文案语言**：演示页健康条、流程阶段面板已**以中文为主**展示；原始 JSON（指标 Tab、事件流）仍为引擎/接口原样。  
2. **技术词**：顶栏不再直接露出 `mock`/`real`/`ok` 等裸枚举（映射为中文说明）。  
3. **引导模式**：前后端均已表达「研究 → 等待选题 → 继续 → 写作…导出」。  
4. **导出**：前端多选与后端落盘格式一致；DOCX/PDF 仍为预留。

## 五、仍建议后续迭代（非本轮必改）

- `GET /v2/runs/{run_id}` 在「引导 continue 完成后」与续跑子图 checkpoint 的语义统一（见 `项目2-引导模式与自动模式设计-v1.md`）。  
- 历史任务列表与只读回放。  
- 运行中动态审批（与 Streamlit 主线对齐的 HITL）。

## 六、结论

**P0 适配项**（引导选题、导出格式、演示页可读性）已在当前仓库**闭环**。剩余缺口主要为**无任务列表 API**与**更深的人机协同审批产品化**，需在引擎与契约扩展后再做前端。
