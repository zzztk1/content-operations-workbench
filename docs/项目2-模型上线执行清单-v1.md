## 本地容器化执行清单

### 前提

当前这台机器还没有 `docker` 命令，所以不能在这里直接完成本地镜像构建验证。

### 等你装好 Docker 之后

在项目根目录执行：

```bash
cd F:\codex\codex1\projects\media-agent
docker build -t media-agent-v2 .
docker run --rm -p 8000:8000 --env-file .env media-agent-v2
```

然后验收：

- `http://127.0.0.1:8000/health`
- `http://127.0.0.1:8000/docs`
- `http://127.0.0.1:8000/demo`

## Render 上线执行顺序

1. 推送仓库代码
2. 在 Render 创建 Web Service
3. 选择项目仓库
4. 使用仓库里的 `render.yaml`
5. 在 Render 补齐 secret 环境变量
6. 绑定 PostgreSQL
7. 首次部署完成后先验 `/health`
8. 再验 `/docs`
9. 再验 `/demo`
10. 最后验 `/v2/run/stream`
