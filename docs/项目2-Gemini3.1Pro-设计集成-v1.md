## 2. 产品定位

**内容工作流运营控制台**：编排 Brief、观测阶段、处理引导暂停、展示质检与导出结果。  
**不是**：通用 CRUD 后台、即时通讯、或脱离引擎的大型主数据录入系统。

---

## 3. 信息架构（四层）

| 层级 | 用户心智 | 与 API 的关系 |
|------|----------|----------------|
| 运行环境态势 | 能否跑、缺什么 key、是否降级 | `GET /health` |
| 任务与策略 | 怎么跑、自动还是引导、导出哪些格式 | `POST /v2/run`、`POST /v2/run/stream`、`GET /v2/workflow-capabilities` |
| 单次运行与交付 | 跑到哪、产出什么、引导时选哪道题 | 响应 `state`；`GET /v2/runs/{run_id}`；`POST /v2/run/continue` |
| 排障与审计 | 出问题怎么对齐日志 | `logs/api_v2.jsonl`、`X-Request-ID` |

首屏优先：**环境 → 任务 → 运行状态**；在无列表 API 前不把「历史检索」做成强承诺。

---

## 4. 导航建议（中文运营文案）

| 分组 | 项 | 说明 |
|------|-----|------|
| 总览 | 控制台首页 | 健康摘要、本地最近 Run ID、快捷发起 |
| 工作流 | 新建任务 | `WorkflowRunRequest` 全量字段 |
| 工作流 | 运行快照与选题继续 | `run_id` 拉快照；暂停时选题 + 继续 |
| 观测 | 流程追踪 | `state.trace` + SSE 序列；强调**流水线阶段**非对话轮次 |
| 质量 | 审核与质检 | `state` 只读；审批在请求体预设 |
| 资产 | 内容与导出 | capabilities + `/outputs` 链接 |
| 系统 | 系统状态 | 完整 `/health` |
| 系统 | 日志说明 | 路径 + Request ID，非实时大屏 |

**一期不做**：多租户、RBAC、菜单配置器、无后端支撑的「全站任务搜索」。

## 5. 页面线框要点

### 5.1 控制台首页

- 顶区：`status`、`graph_version`、关键 `checks`。  
- 卡片：新建任务；**最近 Run ID**（`localStorage` 或粘贴）+ 拉取快照。  
- 限流/关停：`rate_limit_per_minute`、`shutting_down`。

### 5.2 任务页

- 表单与 `WorkflowRunRequest` 一致。  
- 主操作：同步 / 流式（流式受 `enable_sse` 约束）。  
- 结果区：`run_id`、`state.status`；引导暂停时突出选题与「继续」。

### 5.3 流程追踪

- 时间线数据源：`state.trace` + 流式事件。  
- 参考实现：`demo_v2.html` 将节点名**映射为中文**展示，降低英文节点名对运营同学的干扰。

### 5.4 审核与质检

- 只读展示标题、摘要、封面、`cover_visual_review` 等与引擎一致的字段。  
- 文案区分「策略预设」与「运行中人工介入」——后者无专用 API 时不夸大。

### 5.5 导出与文件

- `GET /v2/workflow-capabilities` 为权威说明；docx/pdf 为 reserved。  
- 落地文件在 `outputs/`，经 `/outputs` 访问。

### 5.6 系统状态与日志

- 整页组件化展示 `/health`。  
- 日志：说明 `api_v2.jsonl` 路径；可选展示响应头 `X-Request-ID`。

## 6. 能力对照（诚实清单）

| 体验模块 | 后端现状 | 管理端一期 |
|----------|----------|------------|
| 健康与能力 | `/health`、`/v2/workflow-capabilities` | 可完整做 |
| 发起与流式 | `/v2/run`、`/v2/run/stream` | 可完整做（SSE 关则降级） |
| 引导继续 | `/v2/run/continue` | 可完整做 |
| 快照 | `/v2/runs/{run_id}` | 可完整做 |
| 任务列表 | 无 | 仅本地记 `run_id` |
| 登录权限 | 无 | 不做 |
| 日志检索 UI | 无 | 仅说明路径 |
| DOCX/PDF | reserved | 占位文案 |

---

## 7. 与演示页的关系

- `GET /demo` 提供 **单页** `demo_v2.html`，三栏布局可作为正式管理壳的**低保真参考**。  
- 正式环境可替换为 React/Vue 等，只要保持 `项目2-前后端页面与接口对齐表-v1.md` 中的契约。
