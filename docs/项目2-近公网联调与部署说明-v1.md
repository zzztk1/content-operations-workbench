# 项目2-近公网联调与部署说明-v1

## 当前结论

项目2已经完成本地可体验上线，接下来要做的是：

1. Docker 容器化交付
2. 演示型公网部署
3. 近公网联调验收

## 1. 容器化交付

当前已经具备：

- `Dockerfile`
- `docker-compose.yml`

### 本地 compose 方式

```bash
cd F:\codex\codex1\projects\media-agent
docker compose up --build
```

启动后默认暴露：

- `http://127.0.0.1:8000/health`
- `http://127.0.0.1:8000/docs`
- `http://127.0.0.1:8000/demo`

## 2. 演示型公网部署

当前推荐：

- Render

仓库已经提供：

- `render.yaml`

你只需要在 Render 控制台补齐 secret 变量：

- `STEPFUN_API_KEY`
- `STEPFUN_IMAGE_API_KEY`
- `STEPFUN_VISION_API_KEY`
- `POSTGRES_DSN`
- `LANGSMITH_API_KEY`
- `LANGSMITH_WORKSPACE_ID`（如果需要）

## 3. 近公网联调

部署完成后，先不要急着跑完整工作流，先做表面联调：

### 第一步：基础面

- `/health`
- `/docs`
- `/demo`
- `/v2/workflow-capabilities`

### 第二步：流式面

- `/v2/run/stream`

### 第三步：结果面

- `run_id` 回查
- 图片主图是否可访问
- 视觉质检结果是否出现在导出包里

## 4. 快速验收脚本

当前新增：

- `benchmarks/validate_deployment_surface.py`

本地或公网都可以这样跑：

```bash
set BASE_URL=https://你的部署地址
py benchmarks/validate_deployment_surface.py
```

输出文件：

- `benchmarks/latest_deployment_surface_report.json`

## 5. 这一步的验收标准

至少满足：

1. `/health = 200`
2. `/docs = 200`
3. `/demo = 200`
4. `/v2/workflow-capabilities = 200`
5. `postgres_connectivity = true`
6. `llm_model / image_model / vision_model` 正确显示
