# 工程化交付说明（v1）

最后更新：2026-04-10

## 1. 当前交付范围

项目2当前交付的是一套“可运行、可验证、可演示”的内容工作流系统，而不是单一脚本。

本次交付已包含：

- 旧版 baseline：
  - 自定义状态机
  - SQLite checkpoint
  - CLI / Streamlit
- 新版 v2：
  - `LangGraph StateGraph`
  - `SubGraph`
  - `PostgreSQL Checkpointer`
  - `Step Plan` 真实模型接入
  - `/health`
  - `SlowAPI`
  - 轻量熔断器
  - `graceful shutdown`
  - 图级 `SSE` 事件流
  - `request_id` + JSONL 结构化日志

## 2. 交付目录

- `src/run_workflow.py`：旧版 CLI
- `src/run_workflow_v2.py`：新版 LangGraph CLI
- `src/api_v2.py`：新版 API
- `src/langgraph_v2/`：v2 graph / state / parser / settings / observability
- `benchmarks/`：验证、对比、审计报告
- `logs/`：API / engine 结构化日志
- `outputs/`：导出产物

## 3. 运行模式

### 3.1 Mock 模式

适合：

- 本地结构调试
- 稳定演示
- 避免消耗外部模型额度

关键开关：

```env
LLM_MOCK=true
CHECKPOINTER_MOCK=true
IMAGE_MOCK=true
```

### 3.2 真实模式

适合：

- 跑真实 Step Plan 链路
- 验证 PostgreSQL Checkpointer
- 输出真实结构化结果与审计报告

关键开关：

```env
LLM_MOCK=false
CHECKPOINTER_MOCK=false
STEPFUN_API_BASE=https://api.stepfun.com/step_plan/v1
STEPFUN_MODEL=step-3.5-flash
POSTGRES_DSN=postgresql://...
```
