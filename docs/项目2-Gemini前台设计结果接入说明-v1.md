## 2. 前台设计的核心结论

这轮前台设计的有效结论仍然可用，重点是：
- 页面应定位为“内容运营工作台”，不是聊天窗口，也不是通用后台
- 首页结构适合保留三栏：
  - 左侧：任务配置与运行策略
  - 中间：交付预览与质检
  - 右侧：流程阶段与状态追踪
- 自动模式和引导模式要在首屏明确区分
- 研究候选选题需要单独占一个清晰区域，而不是堆进原始 JSON
- 导出格式要做成显式选择器，并标注“已实现”和“预留”
- 配图、视觉质检、图文一致性等能力应放在“交付质量”语义下，而不是技术开关语义下
