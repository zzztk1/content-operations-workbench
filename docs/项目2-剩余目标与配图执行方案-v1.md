## 4. 还需要继续做什么

### 4.1 第一优先级：把配图变成稳定的产品能力

1. 请求级切换真实配图 / mock 配图  
目的：方便你亲手体验，不再依赖改 `.env` 重启服务。

2. 把真实配图链路写进统一审计  
目的：让功能审计和最新能力保持一致。

3. 更新 demo 使用方式  
目的：让体验页真正成为“图文工作流体验页”，而不是只展示文本结果。

### 4.2 第二优先级：把配图做成简历里更强的工程亮点

1. 图片批量并发  
目标：支持多张图并发生成。

2. 图片退避重试  
目标：让图片服务抖动时仍可恢复。

3. 图片吞吐评测  
目标：给“性能提升”留下结果文件。

4. 图片质检 / 图文一致性检查  
目标：避免只会生图，不会验图。
