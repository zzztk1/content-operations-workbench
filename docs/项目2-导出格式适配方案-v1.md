# 项目2导出格式适配方案（v1）

最后更新：2026-04-11

## Schema 约定

请求体字段：`export_formats: string[]`（可选）

**允许值（归一化）**：

| 请求别名 | 含义 | 落盘扩展名 |
|----------|------|------------|
| `json` | 结构化全量包 | `.v2.json` |
| `md` / `markdown` | Markdown 正文与元信息 | `.v2.md` |
| `txt` / `text` | 纯文本标题+正文+标签 | `.v2.txt` |
| `html` | 极简可打印 HTML | `.v2.html` |

未传或空数组：保持兼容，**仍写入 json + md**（与历史一致）。

## 文件布局

目录：`outputs/`（与现有一致）  
命名：`{run_id}.v2.{ext}`

## 响应 / `content_package`

在原有 `json_path`、`markdown_path` 基础上增加（若对应格式被选中）：

- `text_path`：TXT 绝对路径  
- `html_path`：HTML 绝对路径  

## 预留（不承诺本版本）

- DOCX：需引入模板或 docx 库，另立任务。  
- PDF：可由 HTML 打印链路衍生，另立任务。

## 前端展示建议

- 多选框列出「JSON / Markdown / 纯文本 / HTML」，DOCX、PDF 显示为灰色「预留」。  
- 下载链接可使用已挂载的静态路径 `/outputs/...`（相对站点根路径）。
