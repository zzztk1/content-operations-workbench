# 项目2 前后端页面与接口对齐表（v1）

最后更新：2026-04-11

本文描述 `src/demo_v2.html` 与 `src/api_v2.py` 之间的**字段级**对应关系；集成方可脱离演示页，仅按本表构造请求。

## 页面区块 → 数据需求 → 接口 / 字段

| 页面区块 | 需要的数据 | 后端来源 | 备注 |
|----------|------------|----------|------|
| 任务创建 | `brief`、`platform`、`style` | `POST /v2/run` body | `WorkflowRunRequest` |
| 运行模式 | `run_mode`：`auto` / `guided` | 同上 | 缺省行为以引擎为准；非法值 **422** |
| 审核预设 | `approval_decision`、`approval_note`、`reviewer_threshold`、`max_revisions` | 同上 | 演示页为预设「审批策略」 |
| 配图 / 视觉 | `image_mock`、`cover_candidate_count`、`vision_review_mock` | 同上 + `GET /health` 能力矩阵 | `image_mock` 为可选覆盖（`null` 表示跟随环境） |
| 导出格式 | `export_formats`：`json` `md` `txt` `html`（别名 `markdown`、`text`） | 同上 | 未传时引擎默认 json+md |
| 流程阶段 | `trace`、`events` | 同步响应 `state`；流式 `update` / `final` | 演示页左侧为**中文节点标签**，与 `trace` 中英文字符串一一对应展示 |
| 候选选题（引导） | `research.topics[]`：`title`、`reason`、`heat_score`、`target_audience`、`content_angle` | `state.research` | 停于 `awaiting_topic_selection` 时展示 |
| 选题后继续 | `run_id` + `selected_topic_index`（推荐） | `POST /v2/run/continue` | 亦可传完整 `state`（兼容）；二者兼具时以 **`run_id` 为准** |
| Run 回查 | `run_id` | `GET /v2/runs/{run_id}` | 引导暂停态依赖主图 checkpoint |
| 系统状态 | 模型、mock、checkpoint 等 | `GET /health` | 演示页顶栏为**映射后的中文**，非改接口 |

## 已实现 / 预留（导出）

| 格式 | 后端（`GET /v2/workflow-capabilities`） | 前端展示 |
|------|----------------------------------------|----------|
| JSON | 已实现（`.v2.json`） | 可选 |
| Markdown | 已实现（`.v2.md`） | 可选 |
| TXT | 已实现（`.v2.txt`） | 可选 |
| HTML | 已实现（`.v2.html`） | 可选 |
| DOCX | 未实现（reserved） | 演示页标注预留 |
| PDF | 未实现（reserved） | 演示页标注预留 |

## 演示页与路由

- 静态页：`GET /demo`（`api_v2` 读取 `src/demo_v2.html`，UTF-8）  
- 根路径：`GET /` 返回 JSON，含 `demo`、`health`、`v2_*` 等链接  
- 生产可替换为独立前端，**保持上表请求契约**即可。
