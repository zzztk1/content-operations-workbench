# 项目2页面设计与真实接口映射表

最后更新：2026-04-11

本表用于统一“前台设计”“后台设计”和“当前真实 API / 状态流”。

## 一、前台页面映射

| 页面 / 区块 | 主要数据 | 当前真实接口 / 状态 | 当前状态 |
|---|---|---|---|
| 任务配置页 | brief、platform、style、run_mode、export_formats | `POST /v2/run`、`POST /v2/run/stream` 请求体 | 已实现 |
| 自动模式运行 | `run_mode=auto` | `/v2/run` 或 `/v2/run/stream` | 已实现 |
| 引导模式运行 | `run_mode=guided` | `/v2/run` + `/v2/run/continue` | 已实现 |
| 候选选题面板 | `state.research.topics[]` | `GET /v2/runs/{run_id}` 或流式 final 后回查 | 已实现 |
| 交付预览页 | title、content、tags、cover、visual review | `state` / `content_package` | 已实现 |
| 运行指标页 | metrics | `state.metrics` | 已实现 |
| 事件流页 | SSE events | `/v2/run/stream` | 已实现 |
| 历史回查入口 | run_id | `GET /v2/runs/{run_id}` | 已实现但无列表 |
| 历史任务列表页 | runs[] | 无 | 未实现 |

## 二、后台页面映射

| 页面 / 区块 | 主要数据 | 当前真实接口 / 状态 | 当前状态 |
|---|---|---|---|
| 系统状态页 | status、checks、provider route、checkpoint、langsmith | `GET /health` | 已实现 |
| 工作流能力页 | run_modes、export_formats、routes | `GET /v2/workflow-capabilities` | 已实现 |
| 任务发起页 | WorkflowRunRequest | `POST /v2/run`、`POST /v2/run/stream` | 已实现 |
| 任务详情页 | state、trace、metrics | `GET /v2/runs/{run_id}` | 已实现 |
| 引导继续页 | selected_topic_index | `POST /v2/run/continue` | 已实现 |
| 限流 / 流式探针页 | probe results | `GET /v2/limit-probe`、`GET /v2/stream-probe` | 已实现 |
| 审核中心 | review queue | 无独立审核队列 API | 未实现 |
| 日志查询页 | logs | 仅 `logs/api_v2.jsonl` 文件 | 未实现 API 化 |
| 任务列表页 | runs[] | 无 | 未实现 |

## 三、导出能力映射

| 格式 | 当前真实支持 | 说明 |
|---|---|---|
| JSON | 是 | `.v2.json` |
| Markdown | 是 | `.v2.md` |
| TXT | 是 | `.v2.txt` |
| HTML | 是 | `.v2.html` |
| DOCX | 否 | 前端保留占位 |
| PDF | 否 | 前端保留占位 |

## 四、当前最适合对外展示的说法

- 前台已经是“内容运营工作台”
- 后台已经有“系统状态 + 单任务控制 + 工作流能力”基础
- 真正还没做完的是：
  - 任务列表
  - 审核队列
  - 日志查询 API

## 五、下一步最值得补的接口

1. `GET /v2/runs`：只读任务列表
2. `GET /v2/admin/logs`：只读日志摘要
3. `GET /v2/admin/review-queue`：审核队列
